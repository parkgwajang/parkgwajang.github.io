Google 데이터 접근과 사용

Google 로그인은 사용자가 본인의 Drive에 수집 결과를 업로드하도록 허용하기 위해 사용합니다. rclone은 drive.file 권한 범위에서 앱이 만들거나 사용자가 접근을 허용한 파일을 처리합니다. Google 계정 비밀번호를 수집하거나 저장하지 않습니다.

저장하는 정보

종목명, 종목코드, 주가, 등락률, 거래량, 거래대금, 조회 시각을 휴대폰과 본인의 Google Drive에 저장합니다. API 키와 인증 토큰은 휴대폰의 앱 내부 설정에 보관하며, 결과 파일이나 이 공개 웹사이트에 포함하지 않습니다.

공유 및 분석

수집 파일을 공개 배포하거나 판매하지 않습니다. 사용자가 별도로 Google Drive를 ChatGPT에 연결하고 분석을 요청하면, 해당 파일 내용이 분석을 위해 OpenAI 서비스에 전달될 수 있습니다. 이 연결은 별도로 관리되며 해당 서비스의 정책이 적용됩니다.

보관과 삭제

데이터는 사용자가 삭제할 때까지 보관합니다. 사용자는 휴대폰과 Drive에서 파일을 삭제하고, Google 계정의 연결 관리에서 앱 접근 권한을 철회할 수 있습니다. 접근 권한 철회만으로 기존 파일이 삭제되지는 않습니다.
